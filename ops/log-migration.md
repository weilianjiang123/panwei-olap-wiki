# 系统盘日志改写到数据盘

**操作说明**

数据库和存储服务的日志长期占用系统盘。将原日志入口指向数据盘上的新目录后，需要逐组件验证旧日志仍能查、新日志确实写到新盘，并确认回滚可以保全迁移期间的新增日志。

1. 列出数据库、HDFS、ZooKeeper 各组件实际写入的日志目录、挂载点、权限、可用空间及文件保留要求。核实普通运行日志和审计日志是否走同一位置，先记录各自的验证动作。
2. 在维护窗口按依赖关系停止写入，保留旧目录，在新盘准备对应目录并保持所需属主和权限。切换后按依赖顺序恢复服务，逐节点核对链接解析出的挂载点。
3. 触发一次可识别的业务或审计事件，在新盘验证新记录、采集和轮转，并在旧位置读到历史日志。回滚前检查原盘容量，停止相关写入，分别保全切换前后两段日志，再恢复原目录。

现有记录是经核对的操作方案，没有生产迁移验收结果。
