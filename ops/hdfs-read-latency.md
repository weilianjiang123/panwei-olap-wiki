# 数据节点离线前后 SQL 变慢

**待验证**

一次执行采样中，执行节点在等 HDFS 读块响应。同一事件中，一个数据节点的数据面活动消失，随后两天其余节点的写入增加，部分磁盘出现排队。后来写入和延迟回落，业务也反馈速度改善。

对比相同节点组、相同时段，存活节点的块设备平均写吞吐比此前高约一半。这支持故障后有额外负载。主机采样不能区分副本补齐、表维护和业务写入。另一次耗时更长的 SQL 没有同窗证据表明整个存储集群阻塞了一小时。

区分原因时，把该查询实际等待的读请求、NameNode 同期的欠副本与复制调度、DataNode 单盘延迟和执行端落盘记录放到同一条时间线上。节点已离线、某个时刻连接很多以及事后的一张防火墙快照，都不能单独说明是哪一次查询被拖慢。
