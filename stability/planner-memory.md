# 长 IN 列表使协调节点规划内存持续增长

**测试已验证**

同版本受控回放中，含数千个文本常量的查询在规划期反复比较常量，临时内存在规划过程中持续累积。修正后的对照构建消除了这一路径的持续增长。

固定查询、合成数据、统计信息与优化器，只比较两个构建。与规划消息相关的活分配峰值由约 256 MiB 降至约 14 MiB，计数结果一致。这里比较的是特定内存上下文的活分配，不是整台主机的驻留内存。

遇到类似告警，先区分积累发生在规划还是执行，再比较同一查询的内存曲线、计划和结果。这个回放只验证了一个增长来源。现场是否使用包含修复的版本、是否还有其他高内存会话，需分别核实。
