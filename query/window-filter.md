# 窗口排序前能否先过滤大表

**待验证**

一条全量作业先给大表分组排序，再与小配置表匹配，仅部分分组会进入结果。已有改写方案，现场收益和结果一致性待验证。

如果配置条件对整个窗口分组恒定，可以先用存在性判断保留会匹配的组，再在组内按原排序选取记录。这样可以减少进入排序的数据。保留外层关联和原排序的所有并列判定条件，配置表有重复项时尤其需要核对输出基数。

若过滤会剔除同一组中的部分记录，原先排第一的记录可能改变。用有重复配置、空键、相同时间戳及无匹配项的样本比较结果，再量排序输入行数、临时空间和用时。把全量处理改成增量处理需另行确认迟到数据和补录语义。
