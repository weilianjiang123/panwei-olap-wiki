# Hash 运算落盘后临时文件数超限

**已定位**

查询因单查询工作文件数超过限制而停止。计划中的多个 Hash 算子各获配约 10 MiB，而每个执行节点的估算输入已达 GiB 量级。

临时文件数限制按查询和执行节点生效，与永久表目录项上限是两类故障。单个算子获得的额度还受队列、语句预算和同时执行的算子影响。全局查询参数不能直接当成该算子的额度。

先核对实际行宽、估算误差、最慢节点的倾斜程度，以及 Hash 的分批数和落盘量。可在小范围样本上缩小构建侧或减少中间结果，再观察工作文件数和并发负载。直接放宽文件数上限会把压力转移到临时盘。
