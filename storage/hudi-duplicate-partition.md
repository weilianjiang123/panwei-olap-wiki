# Hudi 外表单分区查询报 Duplicate key

**已定位**

同一物理分区目录里有多个名称以 `.hoodie_partition_metadata` 开头的标记，读取端将该路径识别了多次。限定到这个分区仍报错，测试中也复现了相同异常。

错误发生在枚举分区时，业务数据行尚未参与去重。对比一个正常分区、报错分区和不存在的分区，检查实际分区键、命中的目录和标记文件。只在异常目录找到多份标记，比改写聚合表达式更能解释现象。

至于为何产生多份标记，并行写入是待查方向。处理前保留原目录清单和标记内容，并与写入方确认标准标记。修复后分别验收单分区读取和新写入分区，观察重复标记是否再出现。
