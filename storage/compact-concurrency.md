# 写入期间执行 Compact 会不会阻塞业务

**操作说明**

在核对过的 HORC 场景中，普通 Compact 与追加写入的锁通常可以兼容，同一对象上的 UPDATE 或 DELETE 却可能等待。普通 Compact、FULL 和整表重写的并发影响不同。

先确认是持续追加、原地更新，还是分区级修改，并核对后台任务正在处理哪张表或哪个分区。即使锁兼容，合并的读写也会与业务争用存储。用同窗等待、写入延迟及存储读写量判断实际影响。

FULL 或重新组织整张表会占用额外空间，并可能阻塞业务，适用命令及锁行为要对照目标版本。选一个代表分区或测试表，以正常写入持续时的延迟、文件净增长和查询可用性决定维护窗口。
